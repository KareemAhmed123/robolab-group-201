# 🤖 TU Dresden RoboLab

Autonomous mobile robot project developed as part of the **RoboLab practical course at TU Dresden – Chair of Systems Engineering**.

## Overview

The RoboLab is a practical robotics and software engineering project in which a LEGO EV3-based mobile robot is programmed to autonomously navigate and interact with its environment.

The project combines concepts from:

* Robotics and sensor processing
* Autonomous navigation
* Odometry and localization
* Path planning and graph algorithms
* Network communication
* Software engineering
* Version control and testing
* Team-based development

## Robot Tasks

The robot is designed to perform tasks such as:

* Detecting and following lines
* Recognizing intersections and nodes
* Navigating autonomously through an environment
* Estimating its position using odometry
* Building and using a representation of the environment
* Detecting obstacles
* Computing shortest paths between locations
* Communicating with a central server over Wi-Fi

## Technologies

* **Python**
* **Linux**
* **LEGO Mindstorms EV3**
* **Git**
* Network communication
* Sensor and motor control
* Graph and path-planning algorithms

## Architecture

The software is divided into components responsible for areas such as:

* Sensor acquisition
* Motor control
* Navigation
* Odometry
* Mapping
* Path planning
* Server communication

This separation allows the individual components of the robot to be developed and tested independently.

## What I Learned

The project provided practical experience with:

* Developing software that interacts with physical hardware
* Working with noisy real-world sensor data
* Designing autonomous robot behavior
* Implementing navigation and path-planning algorithms
* Debugging hardware/software interactions
* Developing software collaboratively using Git
* Structuring and testing a larger software project

## About RoboLab

RoboLab is an introductory practical course offered by the **Faculty of Computer Science at TU Dresden** and organized by the **Chair of Systems Engineering**.

The course combines software engineering, algorithms, robotics and teamwork in a practical autonomous-robot project.
